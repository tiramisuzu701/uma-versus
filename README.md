# Uma Versus

A fan-made 2D fighting game starring the Umamusume of Team Spica, in the style of Granblue Fantasy Versus. It runs in the browser as a single HTML file: no install, no server.

**Update 1.7 · build `30ce20`**

- 8 runners, each built around a classic archetype: All-Rounder, Hit and Run, Rushdown, Vortex, Zoner, Bait and Punish, Glass Cannon and Shoto
- Local versus, VS CPU (four levels), Training with frame data and hitboxes, Combo Trials with demos, replays
- Online play with rollback netcode and room codes (peer-to-peer through PeerJS)
- 4 stages and a soundtrack with a theme for every runner

## Play

- **In the browser:** open `index.html`. Everything (sprites, music, fonts) is inside that one file, so it also works offline.
- **On GitHub Pages:** in the repository's *Settings → Pages*, set the source to the `main` branch and the root folder. The game is then served at `https://<user>.github.io/<repo>/` and the wiki at `.../wiki/`.
- **Online matches:** both players need the same build. The build id is shown on the title screen and the main menu.

Default controls (all rebindable under *Controls*):

| | Player 1 | Player 2 | Gamepad |
|---|---|---|---|
| Move | W A S D | Arrow keys | D-pad / stick |
| Light / Medium / Heavy | F / G / H | J / K / L | X / Y / B |
| Skill | T | I | A |
| Throw (L+M) / Super (S+H) | R / Y | U / O | LB / RB |

The full guide to the systems, every move's frame data and every combo is in the wiki (`wiki/index.html`).

| Path | What it is |

| `assets/sprites/` | Packed sprite atlases per runner |
| `assets/music/` | Encoded music tracks |
| `assets/art/` | Logo and tab icons (generated by `tools/make_logo.py`) |
| `vendor/` | Fonts (SIL Open Font License) and PeerJS (MIT), with their licenses |
| `tools/` | Build, wiki and test scripts |

## Building

Requires Python 3 and Pillow (`pip install pillow`).

```sh
python3 tools/build.py          # writes index.html and prints the build id
```

The build id is a fingerprint of `data.js`, `engine.js` and `net.js`: any change to the simulation gives a new id, and players on different ids can't play online together. Cosmetic files (UI, stages, music) don't change it.

Rebuilding the wiki (needs Playwright, see below):

```sh
python3 tools/dump_wiki_data.py && python3 tools/dump_wiki_frames.py && python3 tools/dump_stage_thumbs.py
python3 tools/build_wiki2.py    # writes wiki/index.html
```

The logo and icons: `python3 tools/make_logo.py`.

## Tests

The tests drive the built game in headless Chromium: `pip install playwright && python3 -m playwright install chromium`.

| Script | Checks |
|---|---|
| `tools/test_all.py` | Every listed combo for every runner |
| `tools/test12.py` | Input reader (motions, shortcuts, buffer) |
| `tools/test15.py` | McQueen, Teio and Kitasan mechanics |
| `tools/test_trials.py` | Every combo trial and its demo |
| `tools/test16.py` | Replays and rollback reproduce matches exactly |
| `tools/test8g.py` | Two online clients stay in sync under lag and packet loss |
| `tools/test_music.py` | Music director (themes, round 3, fades) |
| `tools/test_cpu.py` | CPU levels against each other |
| `tools/test_fuzz.py` | Random-input matches for all 64 matchups, checking engine invariants |
| `tools/test_menufuzz.py` | Random key presses through every menu |
